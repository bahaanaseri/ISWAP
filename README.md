# iSwap

انسخ أي شيء من صورة والصقه في أخرى: وجه، شعر، ثوب، سماء، أو شخص كامل.

- تحديد بأشكال (مستطيل، دائرة، مثلث، كامل الصورة) بنقاط قابلة للسحب
- نسخ ولصق بين صورة وثلاث صور، واستبدال تلقائي بين صورتين
- تكبير وتصغير وتدوير بإصبعين، شفافية الحواف، قلب أفقي و180°
- مطابقة الإضاءة والألوان تلقائياً، وتعديل ألوان الجزء الملصوق
- كل المعالجة على الجهاز، لا تُرفع الصور لأي خادم

يعمل في المتصفح عبر GitHub Pages. المصدر في `src/app.html`، وتشغيل `sh src/build.sh` يبني `index.html` في جذر المستودع.
